# licensing

> Generated by the Vibrant Mindz backend scaffold (2026-11-15). Status: experimental, nothing built yet. Plan: `docs/plans/vibrant-mindz-backend/backend-plan.md`.

## What it does

Sells usage rights to digital files, such as beat leases, with tiers, agreements and license checks. Requires `shop` ^0.1, `downloads` ^0.1, `audio-player` ^0.1.

## Use when / avoid when

- Use when: The site sells beats, compositions, sample packs or stock media under license tiers
- Use when: Each sale needs a license agreement the buyer and others can check
- Avoid when: The files are sold outright with no usage terms; use downloads
- Avoid when: The items are physical; use shop

## Settings and env vars

- `free_download_for_email` (bool, default `false`): Offer a tagged free download in exchange for an email
- `credit_line` (string, default `"prod. by Vibrant Mindz"`): Credit printed on every agreement

No env vars; files go through kernel storage.
