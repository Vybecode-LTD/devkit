# kernel/web

Built: `defineModule` (a module's routes and slots), `KERNEL_WEB_VERSION`, and the typed client (`src/api/`): `api`, `useApiQuery`, `useApiMutation` and `apiQueryOptions` for the kernel's paths, `createApiClient<paths>()` for a module's, and `ApiProblem`, thrown by any answer but a success. Its types, `src/api/schema.ts`, are generated from `kernel/openapi.json` (`npm run api:types`; decision 0042). Planned (the rest of K4, `dev plans/contracts/k4-web-kernel.md`): the app shell, `useSession()`, `<RequireAuth>`, `<RequirePermission>`, `useModuleEnabled`, `useSettings`, the slot outlets, and the UI kit lifted from VybeSite (Accordion, Dialog, form fields, Table, Toast, EmptyState, LoadError, SaveConflict, UnsavedDialog, Seo, SignedInDevices, RouteFocus). `index.ts` is the public surface.
