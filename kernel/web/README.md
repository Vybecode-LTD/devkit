# kernel/web

Built: `defineModule` (a module's routes and slots) and `KERNEL_WEB_VERSION`. Planned (phase K4): the app shell, `useSession()`, the generated typed client (`api`, `useApiQuery`, `useApiMutation` over openapi-typescript and openapi-fetch), `<RequireAuth>`, `<RequirePermission>`, `useModuleEnabled`, `useSettings`, the slot outlets, and the UI kit lifted from VybeSite (Accordion, Dialog, form fields, Table, Toast, EmptyState, LoadError, SaveConflict, UnsavedDialog, Seo, SignedInDevices, RouteFocus). `index.ts` is the public surface.
