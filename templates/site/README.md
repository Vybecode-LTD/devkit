# Site template

The empty site `devkit new` starts every project from (built in phase K5): `backend/app/main.py` that builds the app from the kernel and the enabled modules, `alembic/` whose `env.py` loads every branch, `web/` with `src/site/` for the site's own pages, a `Dockerfile`, `railway.toml`, `.env.example`, `CLAUDE.md` and `devkit.lock.json`. Layout: SPEC.md section 4.
