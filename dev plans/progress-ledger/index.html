    Where these numbers come from

    Every step is a row of docs/progress.json in the devkit repo. tools/progress.py turns that one file into docs/PROGRESS.md and into the rows this page reads, so the two always agree, and the repo's tests fail if the document falls behind the file. Progress counts steps, not effort: a module and a kernel phase each count as one step. After v1.0 come the rest of the Vibrant Mindz site, the module waves, the framework tools and the TypeScript port study.
